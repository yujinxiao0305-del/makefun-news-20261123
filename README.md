# The World in One Picture — 23 November 2026

Entry for the make.fun bounty "Sum up 23 November's world news in one image".
`entry.png` is a 1024×1024 dark-newspaper-style infographic: one header plus six
story panels (climate, war, markets, Middle East, US politics, culture), all text
rendered crisply with Python PIL — no AI image generation.
Run `python3 main.py` to copy the bundled `entry.png` to `/output/entry.png`.
